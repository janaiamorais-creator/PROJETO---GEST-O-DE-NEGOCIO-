# Gestão de Negócio

Aplicação de gestão de produtos, estoque e vendas.

## Próxima sessão

Na raiz do projeto, instale as dependências uma vez e suba backend e frontend com:

```bash
npm install --prefix backend
npm install --prefix frontend
npm install
npm run dev
```

O backend ficará disponível em `http://localhost:3000` e o frontend em `http://localhost:5173`.

O banco SQLite persistido está em `backend/dev.db`.
